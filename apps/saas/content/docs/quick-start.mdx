---
title: Quick start
description: Start a private EzPic image edit from upload through prompt, submission, and result review.
---

## 1. Choose a source image

Open the EzPic landing page and select an image you are allowed to edit. The interface validates the
current upload rules before it begins the private upload flow.

## 2. Describe the change

Write a concrete instruction for the edit. Describe the change you want to see rather than a general
topic. You can revise the prompt before submitting the job.

## 3. Continue to the workspace

EzPic may ask you to sign in before the edit is submitted or saved. The draft handoff keeps the
uploaded source tied to the same editing flow.

## 4. Review the result

The workspace reports job progress and the final outcome. A successful image edit can be compared
with its source, downloaded through private access, or used as the starting point for another edit.

Credit handling is described in [Credits](/docs/credits).
