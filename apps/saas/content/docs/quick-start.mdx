Begin in EzImageAI on the [homepage](/#image-editor) or open the dedicated [image editor](/create).
A text prompt is enough to create an image. Add a reference when you want to edit or build on a photo.

## 1. Describe what you want

For a new image, describe the subject, setting, light, and style. For an edit, explain both the
change and the details that should stay the same.

<div className="not-prose docs-prompt-example">

**Change** Replace the background with a pale gray studio backdrop and soft light from the left.

**Keep** Keep the mug, its logo, color, and viewing angle unchanged.

</div>

This is a suggested instruction, not a guaranteed result. Start with one clear change and inspect
the result before adding more. The [prompt-writing guide](/blog/ai-image-editing-prompts) has more examples.

## 2. Add a photo if you need one

Choose a JPEG, PNG, or WebP image you have permission to use. Check the file-size limit shown next
to the upload control; limits can depend on your account and selected model.

A preview appears as soon as you select a file. In the signed-in editor, the upload starts
automatically, so you can write while it finishes. A local preview does not mean the upload is
complete. If it fails, use the retry action or remove the reference.

To create from text instead, leave the reference empty. Text generation requires sign-in.

## 3. Choose a model and review the cost

Open the model selector, then check the available aspect ratio, resolution, and other output
settings. Different models offer different options. The cost shown on the generation button
updates with your selection.

If a model needs a different plan, review the access notice or choose another available model.
You can compare current plans on [Pricing](/pricing). Opening a plan dialog does not purchase it.

When a guest trial is available, its allowance and requirements appear in the editor. Guest
results are temporary, watermarked previews, separate from your account credit balance and History.

## 4. Generate, inspect, and download

Choose **Generate image** or **Start edit** once. The editor runs the required checks and shows
progress beneath your controls. Selecting a preset or signing in does not submit the edit for you.

When the result is ready, inspect faces, lettering, logos, edges, and the details you asked to
preserve. Reference edits offer a before-and-after comparison when both images are available.
Use the download control to keep a local copy.

An eligible saved account result can be opened again from **History**. **Edit again** uses that
result as the source of a new edit, with a new credit cost.

## Resume after signing in or refreshing

The editor can retain your prompt, model, and output choices while you sign in or review a plan.
When browser storage is available, an account draft can also be restored in the same tab and
editor route for up to one hour. Restoring it does not start a new generation.

An image file may need to be selected again after a refresh or sign-in. Read any recovery notice
before continuing. Temporary references expire after 24 hours; an expired reference cannot be
used for another edit. Keep your original file separately.

If a submitted edit is still processing, check its existing result or History before starting
another one. See [progress and recovery](/docs/image-editing#follow-progress-without-starting-over)
for the next step when an upload, check, or generation stops.
