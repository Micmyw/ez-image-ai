EzPic is a browser-based AI image editor. Start from the landing page, upload an image, describe the
change you want, and continue into the editing workspace when sign-in or account access is required.

## What the product does

- Accepts an image as the source for an edit.
- Uses a written prompt to describe the requested change.
- Shows only editing modes currently enabled by the server.
- Tracks each submitted edit as a generation job.
- Keeps source and result assets private and serves them through owner-scoped access URLs.

Use [Quick start](/docs/quick-start) for the shortest path through an edit, or read
[Image editing](/docs/image-editing) for the job lifecycle and result controls.
