EzImageAI is a browser-based AI image generator and editor. Start from the homepage or a [model page](/models),
write a prompt, and optionally add a reference image. Sign in, check the credits on the generation
button, and click once to start;
reference images can also use the available guest trial.

## What the product does

- Creates images from text without requiring an upload.
- Accepts an optional image as the source for an edit.
- Uses a written prompt to describe the requested change.
- Shows generation models and settings currently enabled by the server.
- Tracks each submitted edit as a generation job.
- Keeps source and result assets private and serves them through owner-scoped access URLs.

Use [Quick start](/docs/quick-start) for the shortest path through an edit, or read
[Image editing](/docs/image-editing) for the job lifecycle and result controls.
