EzImageAI creates an image from a written prompt or edits an existing reference. Leave the reference
empty for text to image, or add an image for image to image. Text generation requires sign-in.
The [image-to-image tool](/image-to-image) also accepts a prompt without an uploaded reference.
Leave the image empty to generate from text, or add a reference to edit it. Visitors without an
account are asked to sign in before generating from text.
Start with the [quick start](/docs/quick-start) for your first image. The settings below help you choose an
output before confirming its credit cost; they do not guarantee that every requested change will be exact.

The [model collection](/models) includes twelve image models across Nano Banana, GPT Image, and Seedream.
Each page has its own creative guidance and preselected workspace. Both input modes use the same
listed credit amount for the selected output setting, subject to current availability.
GPT Image 2.5 Flare and Sunburst offer 1K, 2K, and 4K outputs. Their 27:16, 16:27, 9:8, and 8:9
ratios are available at 1K only. Seedream 4.0 accepts instructions up to 5,000 characters and
produces one image per confirmed edit. Availability follows the editor's current model list.

Each image product offers its own output settings, aspect ratios, and input limits. A setting offered
for one product may not be available for another. A successful confirmed edit produces one image.
Output format and background controls, where offered, do not change the displayed credit charge.

Nano Banana and GPT Image 1.5 accept input images up to 10 MB. Your account's upload allowance
also applies; choosing a larger plan does not raise a model's own input limit.

Prompt limits follow the selected model: Nano Banana and Seedream 4.0 accept up to 5,000
characters; Seedream 4.5 and Seedream 5 Lite accept up to 3,000; Seedream 5 Pro accepts up to
5,000. The other models use EzImageAI's 10,000-character limit. Seedream 5 Lite and Pro require at
least three characters. Changing models updates the editor's character limit.

GPT Image 2 supports automatic aspect ratio and background controls at 1K only. Its 4K output
does not support a square aspect ratio. For Sunburst 2K or 4K, choosing a transparent background
also instructs the editor to extract the subject without a backdrop, scenery, or shadow.

Choose an aspect ratio to suit the destination, such as a square layout or a landscape image. Larger
output sizes can be useful when more pixels are needed, but do not guarantee better prompt adherence.
Check the total credit cost after changing settings and before confirming the edit.

## Reference image preparation

In the signed-in editor, choosing a reference immediately displays a local preview while the image
uploads. You can keep editing the prompt and submit when the upload finishes. Clicking Generate
starts the safety checks; the image model only receives a temporary reference after approval.
A local preview alone does not confirm a successful upload. If upload fails, retry it or remove
the reference. Temporary references expire after 24 hours; select the file again if needed.

## Job status

After submission, the result panel appears directly below the editor and reports the current stage
and progress. There is no result placeholder before you select or start a job. You can browse examples
or open account panels while the current job continues to update. A job can finish
successfully, fail, or be canceled only when the server reports that cancellation is allowed.

## Results

A successful image edit provides a before-and-after comparison. Inspect the parts you wanted to keep,
as well as the area you changed. Downloads use temporary private access links; save a local copy if
you need it beyond the retention period. Once a temporary reference expires, its generated result
can still be viewed and downloaded without the original comparison.

A text generation provides a single image preview. Use **Edit again** to turn that output into the
reference for a new edit, or reuse its prompt from History to create another image without a source.
Each new generation requires a fresh credit quote.

The **Edit again** action on an eligible saved account result uses that image as the source for a new
edit. It has a new credit charge. Guest previews stay watermarked and temporary and do not offer this
saved-history workflow. See [Privacy and private media](/docs/privacy) for access and expiry details.

## Choosing a model and output tier

The homepage model menu groups the available models into Nano Banana, GPT Image, and Seedream.
Each entry includes an icon, an editing-style description, supported resolution where applicable,
and its starting Credit amount. The menu only lists models currently available to the service.

The compact output bar opens the aspect ratio, resolution, quality, and supported format options.
Each quality or resolution choice shows its Credit amount. Paired quality and resolution settings
change together, and the selected amount appears on the continue button before you proceed.
The short guidance and privacy notes sit below the homepage editor.
