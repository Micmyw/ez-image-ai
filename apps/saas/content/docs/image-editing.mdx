Use the [image editor](/create) for either a new image or a change to an existing photo.
Leave the reference empty for text generation; add a reference for image editing.
For a first walkthrough, follow [Create your first AI image](/docs/quick-start).

The **Image** category covers both image creation and photo editing. **Video** is marked
as coming soon and cannot be selected yet.

Write in the **Image prompt**, with the optional reference tile beside it. Open the small
**Prompt ideas** button when you need a starting point. Adding a reference switches to an **Edit instruction**.
Tools that require a photo show the reference first and keep generation unavailable until it is ready.

## Add or replace a reference

Use a source where the important subject and details are clear. JPEG, PNG, and WebP are supported;
the editor shows the size limit for your account and model. Upload only images you are allowed to use.

In the signed-in editor, selecting a photo shows its preview and starts the upload. You can keep
writing while it uploads. Generation becomes available when the reference is ready and the other
requirements are met.

If the upload fails, retry it. To continue without a photo, remove it explicitly. An unfinished
or failed reference is not silently ignored and turned into a text-only generation.

New references uploaded in the account editor are temporary and expire after 24 hours. Select the
file again if it expires. A saved generated result has its own retention period and can remain
available after its original reference expires.

## Write the change and the details to keep

Keep the instruction specific. Name the area you want to change, then describe what should remain.

<div className="not-prose docs-prompt-example">

**Change** Turn the background into a quiet street at dusk, with warm light from the shop windows.

**Keep** Keep the person's face, expression, clothing, pose, and framing as close to the original as possible.

</div>

This is a starting prompt, not a demonstrated output. Generative edits can still alter details you
asked to preserve. Compare the result with your source before using it.
Read [How to write AI image editing prompts](/blog/ai-image-editing-prompts) for more guidance.

## Choose a model and output settings

The [model collection](/models) explains the available creative directions. Opening a model page
starts a workspace for that model. Changing the model inside the editor keeps your prompt and
source; review the output settings again because supported options can change.

Open the settings button beside the model to choose aspect ratio, resolution and quality in one panel.
Use aspect ratio for the shape of the image. Use resolution or quality for the available output
tier. Format and background controls appear only where the selected model supports them.
Some quality and resolution choices are linked and update together.

Each generation produces one image; there is no quantity selector. A single supported resolution
appears as information in the settings panel. Controls appear only when the model offers a choice.

Check the credit amount on the generation button after changing settings. A larger image does
not guarantee that a model will follow a difficult instruction more closely. Availability and
account access are shown in the editor; a model's information page is not an availability promise.

## Try a Photo Idea from the Blog

[Photo Ideas](/blog?category=photo-ideas) are visual articles with prompts you can try. Start with
[1980s AI Photos](/blog/1980s-ai-photo) to compare three tested retro styles and their originals.
You can copy a prompt or choose **Use this preset** to prepare the same-page editor with its supported
settings. Selecting a preset does not start a generation or spend credits.

If you have changed the prompt or settings, review the replacement confirmation. Your uploaded
source stays in the editor. Check the recipe's input requirements, current model availability,
and credit cost before choosing Generate. Photo Ideas use the same account and safety requirements
as other edits and do not add a separate free allowance.

## Turn your own photo into a coloring page

Open [Photo to Coloring Page](/photo-to-coloring-page) and upload a photo from your device.
You can also choose **Turn into coloring page** in a result preview or your image library.
This opens the selected image in the tool without generating or spending credits.
Outline, background and A4/US Letter print settings are available inside the tool.
Guest images must still be available in the current session.
Choose simple, balanced or detailed contours, then decide whether to remove or simplify the
background. **Apply coloring settings** replaces the editing instruction while keeping your photo.
Review the prompt, model and credit cost before generating. You do not need to generate an image first.

Download the result or choose **Print / Save PDF**. Select A4 or US Letter and match that size in
your browser's print dialog. Turn off headers and footers. Printing fits the image inside a white
page without cropping; it does not add pixels or convert the image to vector outlines.
AI can change likeness or details, so check the lines before printing. See the tool page for a
labeled illustration and a printable sample.

## Follow progress without starting over

The result panel shows the current stage after you submit. Generation time depends on the model,
queue, transfers, and required checks; there is no fixed completion time for every edit.

| What you see                     | What to do                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| A reference is uploading         | Keep writing while it finishes. Retry a failed upload or remove the reference.                           |
| A prompt or image needs a change | Read the notice, revise the instruction or source, and submit only when ready.                           |
| Generation is running            | Follow the existing result. Avoid submitting another copy just to check progress.                        |
| **Preparing your result**        | The image is being prepared for private viewing. The result and credit summary update as work completes. |
| **Checking result**              | The service is checking the original attempt. A slow response does not confirm failure.                  |
| An edit has failed               | Read the credit outcome, then use **Try again** when offered. A retry is a new generation.               |

A result may become viewable before its credit summary finishes updating. Wait for the task to
complete before using **Edit again**. Only use cancellation when the interface offers it.

If progress remains unresolved, [contact support](/contact) with the visible status and task
reference. Do not include a password or private image-access link.

## Review and continue from a result

A text generation shows a single image. A reference edit can show a before-and-after comparison.
If the original reference has expired, its result may still be viewable without that comparison.

Use **Close preview** to hide the result while keeping your current prompt and source. Eligible
account results remain accessible from **History**, subject to their retention period.
Opening a saved result does not run the generation again.

Choose **Edit again** on an eligible saved result to use it as a new source. Review the prompt,
settings, and new credit cost. Guest previews remain temporary and watermarked and do not offer
the same saved-history workflow.

Download results you want to keep. [Privacy and private media](/docs/privacy) explains retention
and private links; [Credits](/docs/credits) explains charges and pending reservations.
