# Original Ezrapvideo execution material

This is a private server module. Import `@repo/ai/media/rap-templates` only from server execution/admission code. It is intentionally not re-exported by the public AI package index. The browser-safe catalog lives in `@repo/config/video-template-library`.

`source/` copies the original prompt JSON, Rap composition, schemas, request builders and focused source tests from commit `75c06e3b5f8141ac45a3bd37fe494b44cc8f7769`. JSON and the original Spin prompt document retain their exact source bytes. TypeScript adaptation changes import paths, target formatting, ES2021-compatible own-property/index checks, a caller abort signal, and test file paths; prompt string contents and dynamic assembly are preserved.

| Product                          | Original execution retained                                                                                                                                       |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Original Rap and four scenes     | SeeAPI `/v1/generations`, original composition/lyrics, selected source Seedance model, text or ordered portrait references, native audio                          |
| Bulin 47                         | SeeAPI reference-to-video, saved source configuration first, otherwise original freestyle prompt and original scene/optional pose/audio, one portrait, 15 seconds |
| Spin single/duo/trio             | SeeAPI reference-to-video, scene first then ordered identities; original duration/framing/lighting and original generated-instrumental substitution logic         |
| Source Hotel Lobby               | SeeAPI `/v1/templates/hotel-lobby-ai/generations`, two ordered portraits; provider owns its prompt and duration                                                   |

| Green Booth / Kung Fu Cat / Paws | Kie H3 reference mode, current effective source configuration, original ordered references and audio                                                              |

`resolveSourceTemplateRequest` only builds the source semantic request. The caller owns authentication, immutable private input/material bindings, source configuration authorization, quote/cost approval, moderation, credit reservation, execution intent and version freezing. `requiredAssetUrls` are source material identities, never browser output or authorization to fetch arbitrary remote media. Every reference must be mapped to a target private MediaAsset and signed only at authorized execution. No source credit price is returned or used as a target retail price.

The source's explicit Green Booth/pet placeholder JSON remains archived unchanged and unavailable. Actual saved source configurations were read separately, and their six original prompt strings are preserved in `effective-source-prompts.json` with SHA256 hashes. `original-template-configs.json` is an import archive, not runtime-ready configuration: `source-asset:<sha256>` requires an approved private asset binding, and unused public metadata uses `source-metadata:` sentinels. Administrative documents/reference-frame metadata are omitted. This archive preserves source status/rights text but does not attest target rights or generation acceptance; target generation defaults disabled.

`source-manifest.json` records the source commit/path/hash, effective configuration revisions, 19 current effect material bindings and the Flying Car source definitions. `private-assets/` contains exact original media bytes; do not import those binaries into Worker JavaScript or copy them under an app's `public` directory. The original five Bulin/Spin local files matched the separately retrieved source objects. Flying Car has four executable source contracts sharing three original reference packs (19 more files). `archivedSourceMaterials` includes all 38 bindings. Target admission, rights, pricing and asset import remain separate from source request construction.

Flying Car prompt TXT files were copied directly from the fixed Git objects. Their Worker-compatible JSON string container preserves the exact UTF-8 content, including newlines, with byte-equality and source-hash tests. The historical curved-ramp V1 file remains archived but is not selected by a new product key. Showcase uses V5 and ordinary curved ramp uses V6, even though they share the same material pack. Fleet side/front use their original V1 prompts. All retain Kie H3 reference mode, one uploaded subject before the fixed frames, one original audio reference, 16:9, 768P/2K, and 15-second curved-ramp or 7-second fleet durations.

Hosted Hotel Lobby is a complete provider-owned contract, not a missing-prompt template. Its resolved contract declares `executionContract: "provider-owned-template"`, `prompt: null`, and `output.durationSeconds: null`; the actual provider body omits prompt, model and duration. Other contracts declare `executionContract: "prompt"`. Historical snapshots may omit the discriminator and retain their original prompt contract. Input images and generated output still need the target's normal review; no fabricated text should be submitted for prompt review.

Submission is one bounded request with no automatic retry or provider/model fallback. SeeAPI retains its source idempotency header. Kie H3 keeps the exact source body but treats ambiguous 409/429 as uncertain to preserve the target reservation fence; a response containing a conflicting task identity cannot prove rejection. Both transports propagate caller cancellation. Retrieval checks the expected task/model and returns the target's existing `KieVideoV1Result` contract. Provider URLs remain internal until the normal private transfer, verification and result authorization complete.

Focused validation: `pnpm --filter @repo/ai test media/rap-templates`, `pnpm --filter @repo/ai type-check`, and Oxfmt/Oxlint on the TypeScript files in this directory. Do not reformat source JSON: its original byte hashes are intentional. Tests use transport fixtures and the original prompt/material hashes, not paid generation; `targetVerifiedAt` remains null.
