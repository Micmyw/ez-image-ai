## 生成费算式

设参考视频总时长为 `r` 秒，输出固定 5 秒：

```text
单次 Kie credits = 25 × (r + 5)
单次生成费 USD = 0.125 × (r + 5)
批次生成费 USD = 实际收费提交次数 × 单次生成费
```

## 至少 200% 的成本利润率

用户要求的是成本利润率，不是收入毛利率：

代码按以下口径冻结和校验，金额使用整数 USD micros：

```text
D = 生成 + 图片/参考/输出/提示词审核 + 运行 + 存储/传输
C = ceil(D / (1 - 经批准的失败损耗率))
g = 最低实际折后毛收款 / 全部发放积分（包含赠送及年付积分）
R = 本次积分数 × g
F = ceil(R × 经批准的支付费率) + 经批准的支付固定分摊
N = R - F
成本利润率 = (N - C) / C
要求 (N - C) / C >= 200%，即 N >= 3 × C
```

完整成本记录列明支付费 `F`，并在净收入中扣除；解释利润时不重复从 `C` 扣除同一笔费用。现有整数求解器采用更保守的 `R >= 3 × (C + F)`，随后再硬校验 `N >= 3 × C`，因此可能比最低门槛多收积分。这是单订单变动成本贡献利润，不是含公司人员、税费和全部固定开支的企业净利润。不能用单次供应商生成费代替完整成本，也不能只看最高价充值档。

当前目录最低付费积分收入 floor 是 **21,944 µUSD/credit**（Studio 年付 $790 / 36,000 积分，向下取整）。这是未扣支付费的目录毛收入依据；实际可购买折扣若更低，必须批准更低的 `g` 并重算。`revenue.minimumGrossUsdMicrosPerCredit` 明确保存这个毛收款 floor，而非净值；同时必须填收入依据、到期时间和实际支付费率。代码拒绝高于目录最低值的审批，但不能靠非空依据文本证明商户账单，故实际凭据不足时仍不准开放。

合成边界测试假设 `D=$0.519510`、失败损耗率10%，得到 `C=$0.577234`；支付费8%加$0.001，毛收入 floor 21,944 时求得105积分、`N=$2.118790`，贡献利润率267.05%。仅把毛收入 floor 改成15,000时求得153积分、`N=$2.110400`，利润率265.60%。这些生成、审核、运行及费率数字均为测试假设，**不是 Standard reference 正式报价或批准的优惠**。真实价格需要按本功能完整成本和全部可购买优惠重新审批。
