## Static source and rollback

`apps/blog-ads` is an assets-only Cloudflare configuration for `ezimageai-blog-ads-production`, custom domain `ads.ezimageai.com`, with no user Worker entry point, binding, database, secret, new dependency or deployment script. Cloudflare documents free static asset requests; this work does not upgrade a plan or enable a paid resource.

Generation defaults to empty documents. An explicit future deadline (at most two hours) builds the test documents from the original placement template; pinned fingerprints reject unreviewed template/unit/style/host changes. HTTP CSP hashes only the reviewed inline configuration/bootstrap and style. Each document permits only its own supplied loader origin for script/image/frame/connect traffic. It forbids inline attributes, workers, forms, objects, popups, top navigation and same-origin sandbox permissions. `frame-ancestors` permits only `https://ezimageai.com`; cache, referrer, indexing and browser capabilities are restricted. A standalone top-level visit runs no supplier loader. The child navigates itself to `about:blank` at expiry, ending its execution realm.

The initial **OFF** source was deployed at 11:34 UTC, version `170d699f-6a84-4a26-8146-9b46e08bef80`. Both HTTP documents returned 200 with the expected restrictive headers. Local assets contain no scripts, but the zone injects an existing Cloudflare Insights beacon into online responses. The child CSP excludes that origin; this is an explicit rejection to verify, not a reason to add it. Never describe the online HTML as completely script-free.

The rollback is to regenerate without `--test-until` and deploy the empty documents, while leaving both main switches off. Verify both HTTP responses after rollback. The finite main preview also expires even if rollback is delayed, and a loaded child ends itself at the same deadline. Never widen domains or sandbox capabilities to make a creative work.
