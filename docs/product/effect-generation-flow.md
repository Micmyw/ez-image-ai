# Hotel Lobby and Raindance generation flow

The signed-in workbench displays the protected access API's complete order price and eligible paid-credit balance before uploads. Account totals remain separate because other credits cannot fund these videos. The public price is not a provider-only estimate.

Once sealed photos are ready, Generate requests a fresh protected quote and submits the same displayed total in one action. Any price change, up or down, stops before acceptance and requires a new explicit confirmation. No client-supplied amount enters the acceptance API. A changed photo or role swap invalidates the unsubmitted quote. The server still owns moderation, availability, funding, atomic reservation and idempotency.

Missing-photo actions open the relevant upload input. Insufficient eligible credits make Add credits the primary action. Owner-scoped session drafts retain sealed asset IDs, the template and Raindance mode; raw photos, signed URLs and upload URLs are not persisted. A checkout return is armed by this workbench and bound to the actual durable payment intent before it can redirect. Only the exact template and optional validated solo/duo mode survive in that return URL.

A confirmation is saved before acceptance. Unknown outcomes recover the immutable request and idempotency key, including after refresh or a balance change. Known expired/rejected quotes clear only unaccepted confirmation state. Leaving a mode before its quote returns cannot submit a hidden order; an already accepted task keeps running and can be recovered from private history. A completed acceptance exposes Make another video before a second order can start. Blocked recovery storage stops acceptance and the credit purchase handoff.

The separate Rumpelstiltskin entry retains its existing explicit quote/review flow. This change does not change prices, duration, providers, audience, safety, ledger or payment contracts. Local browser verification uses synthetic authentication, authorized fixture pixels and mocked business APIs; it is not paid generation or supplier-quality evidence.
