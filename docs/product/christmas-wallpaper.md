Dark retains pine detail and adds soft face illumination when a reference is supplied. Scene-only prompts include the setting without the reference-subject directions. Both screen compositions keep each style's focal arrangement together.

PNG output contains only pixels from the source; screen controls stay in DOM overlays. Downloads never upscale; the exact cropped dimensions are displayed.

Result identity and lifetime follow the selected result panel, including job switches, closure, account changes and expiry. Private previews use the existing account-scoped access query. Changing a style does not relabel or replace an existing generated output.
