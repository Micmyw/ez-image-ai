# EzImage 图片 / 视频共用工作区

验证时间：2026-10-08（GMT+8）。

## 实现范围

- 首页与 /create 在原生成区域内提供 Image / Video 切换，保留 EzImage 紫色品牌。视频使用相同容器和标题系统：左侧参考图、主提示词、底部紧凑工具栏、右侧确认操作。
- 视频模型弹层使用左侧模型家族、右侧实际模型与能力信息。参数集中为比例、时长、分辨率和固定单个结果；音频依据现有模型合同显示。未实现或当前无可用报价的能力禁用。
- 两种模式保持独立草稿和上传生命周期；切换不卸载已访问的生成器。浏览器返回/前进同步模式与焦点，关闭隐藏面板的弹层，暂停隐藏视频播放，保留后台任务卡。
- /video 仍经过原登录边界，再跳转 /create?mode=video；旧 job 链接映射为 videoJob。视频历史、私有播放与下载继续使用现有接口。
- 模型或参数变化校验完整合法组合并作废旧报价。确认使用真实后端报价；同步点击锁防止重复提交，未知网络结果保留原请求与幂等键；确定的入队前拒绝允许重新编辑。
- 登录前仅通过明确的工作区登录动作交接两种游客草稿。参考图 File 不跨登录授权边界，恢复时明确要求重选；不静默转成纯文字生成。视频草稿及待确认请求按账号隔离。
- 图片草稿保存模块和视频详细翻译保持按需加载。登录交接等待两份草稿保存完成，并在保存期间锁定工作区，避免慢网下继续编辑或重复点击造成草稿丢失。
