# Homepage model recommendations

The homepage's “One workspace. Different possibilities.” section recommends these
models in order:

| Row    | Models                                        | Destinations                                           |
| ------ | --------------------------------------------- | ------------------------------------------------------ |
| First  | Seedream 5.5, MiniMax H3 Image, GPT Image 2.6 | `/seedream-5-5`, `/minimax-h3-image`, `/gpt-image-2-6` |
| Second | GPT Image 2, Nano Banana Pro, Seedream 5 Lite | Their existing `/models/*` pages                       |

Desktop retains three columns; narrow screens follow the same order in one column.
Cards retain a consistent 3:2 frame. Static covers use the responsive WebP pipeline.
The GPT Image 2.6 card contains its square animation without cropping the moving wings.

Seedream uses the Kie-provided sourdough example. MiniMax uses the existing verified
cloud-sanctuary output documented in `../operations/evidence/minimax-h3-live-generation-2026-11-13.json`.
GPT Image 2.6 uses an origami-hummingbird GIF generated through the production EzImageAI
editor with Sunburst. The unchanged downloaded GIF is 512×512, nine distinct frames at
200 ms each, looping indefinitely. Its receipt is kept in
`../operations/evidence/gpt-image-2-6-gif-2026-11-13.json`. The earlier botanical poster
and its separate Kie-playground receipt remain historical assets.
The three second-row images remain concept artwork and retain a visible disclosure.

The GIF loads only when its card enters view. Leaving the viewport, hiding the tab or
pressing Pause returns to the small first-frame WebP. Reduced-motion users see that
poster by default and can explicitly play. The playback button is outside the model
link. Account-access and settlement evidence is tracked in
`../operations/image-generation-access-2026-11-13.md`.

This section keeps its existing English copy convention. Homepage experiment metadata
and H1 translations, model access, billing and indexability are unchanged.
